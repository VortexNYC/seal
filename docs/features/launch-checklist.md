# Pre-Launch Checklist

Operational items that must be completed before public launch. These are not code features — they're process/verification gates.

## Compliance Verification

- [ ] Consent flow tested with real users
- [ ] Legal review completed (consult with attorney)
- [ ] Security audit passed
- [ ] Penetration testing completed

## Infrastructure

- [ ] Backup and disaster recovery procedures documented
- [ ] Monitoring and alerting for audit system health
- [ ] Alert workspace admin when audit logging consistently fails

## Process

- [x] Support workflow for receiving manually-signed documents back (ESIGN opt-out)
