# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security reports.

Email **security@vortex.nyc**, or use the contact in
`/.well-known/security.txt` on seal.nyc / docs.seal.nyc.

Include: affected route/component, reproduction steps, and impact.

Published VDP: https://docs.seal.nyc/getting-started/security

## Scope

Seal is a self-hostable Cloudflare Worker product. Reports about code in this
repository and hosted seal.nyc are in scope. Misconfiguration of your own
self-host deployment (secrets, domains, access policies) is yours to manage.

## Bounty

No paid bug bounty program yet. Responsible disclosure is appreciated; we do
not currently offer cash awards.
