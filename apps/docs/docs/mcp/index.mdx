# MCP Integration

The Seal MCP server lets agents (Claude, Devin, Codex, Cursor, etc.) operate your
workspace over the **OpenAPI contract** — upload, place fields, send, webhooks,
PDF ops — while **humans** apply signatures on the signing link.

MCP must not invent endpoints missing from [OpenAPI `/reference`](/reference).

## MCP server URL

```
https://mcp.seal.nyc
```

## Quick setup (Claude Desktop)

```json
{
  "mcpServers": {
    "seal": {
      "url": "https://mcp.seal.nyc",
      "auth": {
        "type": "oauth",
        "authorizationUrl": "https://mcp.seal.nyc/.well-known/oauth-authorization-server"
      }
    }
  }
}
```

1. Authorize when prompted and pick an organization.
2. Prefer a guided prompt: *“Use the Seal send-document prompt”* — or call tools directly (`seal_upload_file_content`, `seal_create_document`, `seal_create_document_field`, `seal_add_recipient`, `seal_send_document`).
3. When a human must sign, use **`seal_get_interaction`** / **`seal_wait_interaction`** (InteractionSession) — agents do not sign. See [Agents & who signs](/docs/getting-started/agents#human-handoff-interactionsession).

Automation without MCP OAuth: create an API key and use the **`seal` CLI** or `@vortex-api/seal` — same contract.

## Typical agent workflow

1. Upload PDF (`seal_upload_file_content` or REST upload URL)
2. Create document → add recipients
3. Place fields (`seal_create_document_field` or template / field suggestions)
4. Optional: `seal_apply_document_bindings` for deal data (`binding_key`)
5. Send → human signs on `/sign/$token`
6. Webhooks or poll → `document.completed` → download + audit

Proof from the repo:

```bash
SEAL_API_KEY=seal_… pnpm run prove:golden-path
SEAL_API_KEY=seal_… node scripts/smoke-prod.mjs
```

## OAuth endpoints

- **Authorization server:** `https://mcp.seal.nyc/.well-known/oauth-authorization-server`
- **Protected resource:** `https://mcp.seal.nyc/.well-known/oauth-protected-resource/mcp`

See [MCP Authentication](/docs/mcp/authentication) for scopes and token lifecycle.

## Security

- Organization-scoped access; revocable from Settings → Developer
- MCP actions appear in document audit trails where applicable
- Use webhooks + `verifySealWebhookSignature` from `@vortex-api/seal` for production ([verification guide](/docs/webhooks/verification))

## Limits

Same as REST: **60 req/min**, **1000 req/hour**. Large PDFs: prefer upload URL + base64 MCP upload for smaller files.
