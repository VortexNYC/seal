### Document workflow

| Tool | Summary |
| ---- | ------- |
| `seal_bulk_send_documents` | Send multiple draft documents for signing at once. Maximum 50 documents per request. Each document is invited the same way as a single send, including sequential order. | `seal_forward_envelope` | Start a new draft envelope from the executed PDF of a completed document. The new envelope has that signed file and no signers. Use this when someone else must sign the finished PDF. Fails if the document is not completed. |
| `seal_get_document_access` | Get the sharing/access mode for a document. Returns whether the document is private (owner only), workspace (all org members can see it), or specific (only explicitly granted users). Useful for auditing document visibility before sharing. |

Options: 'private' (owner only — the default), 'workspace' (all org members can view, requires Pro plan), 'specific' (only explicitly granted users, requires Pro plan).
