# Getting Started

## What is Seal?

Seal is a document platform built for agents. The model — Claude, Devin, Codex,
whatever you run — drives the work through a typed API; humans provide the
signing intent. Three capabilities:

**Send & sign** — upload a PDF, place fields, add recipients, send. Humans
open a link, sign, done. You get the completed document, a certificate of
completion, and a tamper-evident audit trail. This is the DocuSign-class
workflow: contracts, NDAs, approval flows.

**Document tools** — deterministic PDF operations you can call like functions:
extract text and layout, split, merge, compress, redact, watermark, OCR,
convert to Office formats, compare two versions. No model calls — pure
document manipulation, safe to run unattended.

**Review** — give your agent a spreadsheet to fill out. Create a matrix with
documents as rows and questions as columns; the agent reads each document
through `preview`, reasons on its own infrastructure, and posts answers to
`cells`. Every answer must anchor to a verbatim quote — fabricated citations
collapse to `not_found`. Use it for clause extraction, due-diligence sweeps,
and contract comparison across a batch.

Seal never runs inference. There is no hosted model, no chat, no AI output
generated on our side — agents bring their own reasoning; Seal provides the
tools and the evidence.

## When to use what

| You want to…                                        | Reach for                          |
| --------------------------------------------------- | ---------------------------------- |
| Get a contract signed                                | `documents` → `recipients` → `send` |
| Inspect or transform a PDF without signing           | `documents/preview`, `pdf/*`       |
| Extract structured answers from many documents       | `reviews` (matrix + cells)          |
| Propose redlines a human must approve                | `revisions`                         |
| Be notified on views, signatures, completions        | `webhooks`                          |
| Audit who did what                                   | `audit-log`, `signatures/verify`    |
